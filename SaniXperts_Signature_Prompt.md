## INSTALL INSTRUCTIONS (give this to each employee)

**Microsoft Outlook:**
1. Open the HTML file in Microsoft Edge (not Chrome)
2. Press Ctrl+A (select all) then Ctrl+C (copy)
3. Open Outlook → File → Options → Mail → Signatures → New
4. Give it a name (e.g. "SaniXperts")
5. Click in the signature box → press Ctrl+V (paste)
6. Click OK → OK

**Gmail:**
1. Open the HTML file in any browser
2. Press Ctrl+A then Ctrl+C
3. Go to Gmail Settings → See all settings → General → Signature → Create new
4. Paste with Ctrl+V
5. Save changes
